# 轻循

参考用户提供的卡卡瘦界面制作的手机端页面原型。奶油纸感底色、深绿色文字、浅绿 / 鹅黄 / 珊瑚色卡片；包含今日、周期、记录、跟练和日历。首页直接从热量收支开始。

## 本地预览

使用 Node.js 启动：`node server.cjs`，访问 http://localhost:4173 。也可直接用浏览器打开 index.html。

## 当前可体验

- 喝水快捷记录、目标与提醒偏好设置。
- 经期日期录入与粗略阶段估算、身体感受记录。
- 饮食照片选择与压缩预览、手动食物 / 份量 / 热量记录。
- 首页体重趋势线，围度入口进入后展示胸围、腰围、臀围、大腿围、上臂围、小腿围的独立记录和趋势线。趋势使用最近 30 次真实记录，按实际日期间距绘制；只有一条记录时只显示点，不伪造历史。
- 运动总打卡与肩背、臀腿、体态、拉伸四类彩色独立勾选；类别勾选会同步当天运动状态，撤销总打卡会清除当天类别勾选。
- B 站（粉色）/ 抖音（绿色）链接收藏；可从抖音分享文字提取链接。分类为全部、肩背、臀腿、体态、拉伸；旧的全身收藏自动迁到体态，腿臀迁到臀腿。
- 手动记录 Apple Watch / 健康 App 的当天静息能量与活动能量。总消耗仅把两者相加一次，不再次加上单次训练消耗；饮食与消耗均确认全天完整后显示估算热量缺口，缺少数据时不输出全天结论。
- 月历切换、日期记录回看；经期粉色、卵泡期绿色、黄体期黄色、黄体后期蓝色，与周期页一致。选中日期保持阶段底色，用轮廓标记。
- 每次输入新的经期开始日会保留以前的周期记录；同一天重新填写会更新该记录。只着色已记录开始日之后一个设定周期的范围，不把历史无限循环外推。
- PWA 桌面图标、安装提示、离线页面缓存。首次需在线访问，所有资源使用相对路径，支持 GitHub Pages 项目子路径。
- 数据保存在当前浏览器 localStorage，不进入 Git 仓库，也不上传服务器。

## 添加到手机桌面

线上页面需通过 HTTPS 访问。电脑本地的 `127.0.0.1` 网址无法直接在手机使用。

- iPhone：Safari 打开线上页面 → 分享 → 添加到主屏幕。
- 安卓：Chrome / Edge 打开线上页面 → 菜单 → 安装应用 / 添加到主屏幕。
- 首页底部的「添加到手机桌面」会在浏览器支持时请求安装，否则展示操作说明。最终添加需在用户手机完成。

可将本仓库 `main` 分支根目录设为 GitHub Pages 发布源；`.nojekyll` 已提供。常规项目网址为 `https://jeffzepher.github.io/lose_weight/`，以 GitHub 实际部署状态为准。

## 验证

`node --test tests/app.test.cjs` 检查阶段边界、历史周期、收藏链接校验、围度保存、分类迁移和安装所需资源。尚需在真实 iOS / Android 设备验证安装与浏览器存储行为。

## 页面原型的边界

尚未接入 AI 食物识别、营养分析、个性化热量目标算法、手机通知、账号与云端同步。Apple Watch 自动同步需要支持 HealthKit 的原生 iPhone App 和用户授权；网页 / PWA 仅提供手动录入。当前热量差额是记录数据的算术估算，并非精确测量或饮食处方。提醒设置不触发系统通知。照片和健康信息仅在本机浏览器保存；清除浏览器数据后会丢失，请勿当作正式健康档案。

周期估算使用输入的平均周期与经期天数，黄体期边界按下次预期经期前约 14 天粗略划分，最后 5 天作为黄体后期展示；不确认排卵，不可用于避孕或诊断，超出预设周期时提示更新。未假设用户实际经期日期，也没有生成个体化热量处方。身体档案默认留空，年龄、身高、体重等个人信息由使用者在本机填写，不包含在公开源代码中。

当前原型不启用 16:8 断食，避免将参考产品中的功能直接变成用户默认计划。
